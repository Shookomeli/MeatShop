# دستورالعمل استقرار، پشتیبان‌گیری و نگهداری سیستم در ویندوز (Windows Deployment Guide)

این راهنما مراحل راه‌اندازی و نگهداری نرم‌افزار فروشگاه گوشت و مرغ را بر روی کامپیوتر یا سیستم صندوق فروشگاه (Windows 10 / 11) تشریح می‌کند.

---

## ۱. ساختار پوشه‌های عملیاتی

برای جداسازی کامل داده‌های حساس و جلوگیری از بازنشانی یا حذف سهوی دیتابیس در زمان ارتقای کدها، مسیرهای زیر بر روی سیستم ایجاد می‌شوند:

- **پایگاه داده عملیاتی تولید (Production):**
  `C:\MeatShop\data\db.sqlite3`
- **پوشه نسخه‌های پشتیبان (Backups):**
  `C:\MeatShop\backups\`
- **پوشه لاگ‌ها و سوابق:**
  `C:\MeatShop\logs\`

---

## ۲. متغیرهای محیطی تولید (`.env`)

فایل `.env` را در ریشه پروژه با مقادیر زیر تنظیم نمایید:

```env
SECRET_KEY=یک_کلید_محرمانه_طولانی_و_پیچیده
DEBUG=False
SCALE_MODE=mock
CURRENCY_DISPLAY_UNIT=RIAL
DATABASE_PATH=C:\MeatShop\data\db.sqlite3
```

---

## ۳. مراحل راه‌اندازی اولیه

1. فایل `scripts\windows\setup_environment.bat` را با کلیک راست و انتخاب **Run as Administrator** اجرا کنید.
2. این اسکریپت پوشه‌های مورد نیاز را ساخته، کتابخانه‌ها را نصب کرده و مایگریشن‌ها را روی دیتابیس اعمال می‌نماید.
3. جهت راه‌اندازی اولیه کاتالوگ در محیط فروشگاه، کاربر مجاز می‌تواند کالاها را از طریق فرم‌های نرم‌افزار تعریف کند یا در صورت نیاز از دستور زیر استفاده کند:
   ```cmd
   python manage.py seed_tare_types
   ```

---

## ۴. اجرای روزانه سیستم فروشگاه

- با اجرای دوبار کلیک بر روی `scripts\windows\start_shop.bat`، سرور داخلی بر روی پورت `8000` بالا می‌آید.
- پرسنل می‌توانند از طریق مرورگر به آدرس `http://localhost:8000` متصل شوند.
- در صورت نیاز به اجرای سرویس خودکار همزمان با روشن شدن ویندوز، می‌توانید میانبر این فایل را در پوشه `Startup` ویندوز (`shell:startup`) قرار داده یا با ابزار `NSSM` آن را به عنوان Windows Service ثبت نمایید:
  ```cmd
  nssm install MeatShopService "C:\Python311\python.exe" "manage.py runserver 0.0.0.0:8000"
  ```

---

## ۵. پشتیبان‌گیری خودکار روزانه (Windows Task Scheduler)

برای جلوگیری از اتلاف داده‌ها:
1. برنامه **Task Scheduler** ویندوز را باز کنید.
2. یک تسک جدید با عنوان `MeatShop_Daily_Backup` بسازید.
3. زمان اجرا را هر شب ساعت **۲۳:۰۰** تعیین کنید.
4. دستور اجرا را به فایل `scripts\windows\backup.bat` متصل نمایید.
5. این اسکریپت با بهره‌گیری از SQLite Online Backup API یک نسخه مطمئن بدون قفل شدن سیستم ایجاد نموده و نسخه‌های قدیمی‌تر از ۳۰ روز را پاکسازی می‌کند.

---

## ۶. بازیابی پایگاه داده (Restore)

در شرایط اضطراری، جهت بازیابی یک فایل پشتیبان:
```cmd
python manage.py restore_database "C:\MeatShop\backups\meatshop_backup_YYYYMMDD_HHMMSS.sqlite3"
```
این دستور پیش از هر تغییری در پایگاه داده مقصد، موارد زیر را بررسی می‌کند و در صورت هر خطا، پایگاه داده فعلی دست‌نخورده باقی می‌ماند:
- یکسان نبودن مسیر فایل پشتیبان و پایگاه داده مقصد؛
- سلامت فایل با `PRAGMA integrity_check`؛
- وجود جداول اصلی این نرم‌افزار (کالاها، فاکتورها، دفتر گردش انبار و `django_migrations`)؛
- عدم وجود مهاجرت‌های ناشناخته (فایل پشتیبان ساخته‌شده با نسخه جدیدتر نرم‌افزار پذیرفته نمی‌شود).

برای آزمایش بازیابی بدون دست زدن به پایگاه داده اصلی، از گزینه `--target-db` با یک مسیر آزمایشی استفاده کنید:
```cmd
python manage.py restore_database "C:\MeatShop\backups\meatshop_backup_YYYYMMDD_HHMMSS.sqlite3" --target-db "C:\MeatShop\restore_test\db.sqlite3"
```
پس از بازیابی یک نسخه پشتیبان قدیمی‌تر، دستور `python manage.py migrate` را اجرا کنید.
